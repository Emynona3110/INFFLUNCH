PROMPTS ICÔNES SUCCÈS — INFFLUNCH (Midjourney / Recraft / Gemini)
================================================================================

À SAVOIR : Midjourney et Gemini génèrent du RASTER (PNG), pas du SVG — d'où
les étapes 2 à 4. Recraft, lui, sort du SVG directement : les étapes 2-3
sautent, et avec elles la dérive de couleurs et de cadrage. Workflow raster :
  1) Générer chaque icône une par une (prompts ci-dessous, bloc de style inclus).
  2) Fond UNI (une seule couleur plate, pas de décor ni de dégradé), carré,
     haute résolution. Aucune couleur n'est imposée : le détourage se fait à la
     main sous PHOTOPEA (décision du user, 2026-09-29 — le fond chroma key vert
     imposé la veille est abandonné). Seule contrainte : que le fond ne soit pas
     de la même couleur qu'un trait, sinon il emporte le dessin avec lui.
  3) Détourer le fond sous Photopea, puis vectoriser en SVG propre (4 aplats) :
     - Illustrator : Objet > Vectorisation de l'image (Mode Couleur, Palette
       limitée 4 couleurs), régler "Ignorer le blanc"/fond > Développer, puis
       forcer les hex exacts et supprimer le fond tracé.
     ⚠️ C'est CETTE étape qui fait dériver la série : le vectoriseur invente
     ses propres teintes (on a aujourd'hui une quarantaine de bleus et
     d'oranges en base au lieu de 2) et recadre au plus près du dessin (des
     viewBox de 384 à 2048). Forcer les hex ET un canevas carré identique.
     - ou gratuit : vectorizer.ai / Inkscape (Tracer le bitmap) / potrace.
  4) Nettoyer + exporter SVG (attributs de présentation, minifié), passer SVGO.

Astuce : nomme le fichier final avec l'ID indiqué (ex. anti_panurgisme.svg),
range-les dans public/achievements/ pour l'intégration ensuite.

Suffixe utile à ajouter à un prompt si besoin (rappel format) :
  "1024x1024, plain solid background, single centered icon."

Style commun (rappel, MIS À JOUR le 2026-09-29) : Very simple minimalist flat
vector icon, single centered subject, few large clean geometric rounded shapes,
thick uniform royal blue outlines (#113894), flat shading only, mostly off-white
fills with one small warm orange accent, strict three-colour palette (deep royal
blue #113894, warm orange #EA580C, off-white #FAF8F4), no text, plain solid
background, square 1:1.

Palette : TROIS couleurs — bleu (contours), orange (accent PONCTUEL), blanc
cassé (dominante). Référence : `berger_dun_jour` (19 formes blanches, 4 bleues,
UNE seule orange). ⚠️ Le NOIR a été ajouté le 2026-09-28 puis RETIRÉ le
2026-09-29 : le style visé n'en contient pas. Ne pas le remettre.
Le fond n'appartient pas au dessin : il est uni et retiré sous Photopea.

Pour Midjourney (abonnement en cours) : générer UN code de style une fois
(`--sref random`), noter le numéro et le réutiliser sur les 26 prompts, avec
`--style raw` (sinon MJ ajoute sa patte par-dessus le prompt) et la version
figée (`--v 7`). Toute la série dans UNE session : les icônes actuelles ont été
faites par vagues, avec deux outils, c'est la première cause d'hétérogénéité.
